# MusicMV 画幅比例节点

公共 ComfyUI 生图工作流使用的尺寸选择节点。它提供常用画幅下拉选项，并输出宽度和高度两个整数。

## 预设

- 16:9：1280×720
- 9:16：720×1280
- 1:1：1024×1024
- 4:3 / 3:4：1152×864 / 864×1152
- 3:2 / 2:3：1248×832 / 832×1248
- 5:4 / 4:5：1120×896 / 896×1120
- 21:9：1344×576
- 自定义尺寸：宽高按 8 像素步进

预设尺寸控制在约 1MP，适合 RealVisXL/SDXL 与 RTX 3060 12GB 的单张生成。

## 安装

将本目录复制或链接到 ComfyUI 的 `custom_nodes/musicmv_aspect_ratio/`，然后重启 ComfyUI。
