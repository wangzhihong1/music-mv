# 《故乡》音乐风格

## 风格定位

- 主风格：低沉男声慢唱叙事民谣
- 融合风格：木吉他故事歌、黄昏乡土室内乐
- 年代感：当代
- 地域或文化元素：中国乡土田野的日常质感，泥路、草、庄稼与云；不民俗符号化，歌词不出现「农村」
- 整体气质：字少、拍多、唱得很慢；傍晚的、干而沉的感慨

## 音乐参数

- BPM：58
- 拍号：4/4
- 调性：A Minor，用 C 与 F 增加田野的空，不转大调催泪
- 建议时长：约 03:40–04:20，最终时长待用户确认
- 段落结构：8 小节 Intro / Verse 1 / Pre-Chorus 1 / Chorus 1 / Verse 2 / Pre-Chorus 2 / Chorus 2 / Bridge / Final Chorus / Short Outro

## 编曲设计

- 核心乐器：磨损钢弦木吉他、低音贝斯、刷奏、低沉大提琴长音；钢琴很少或不用
- 节奏与律动：每小节只走四个缓慢拍点，不要填满细分；吉他慢拨，主唱后于拍点
- 和声走向：主歌在 Am–F–C–G 间慢走；副歌不转调、不抬调
- 前奏设计：8 小节木吉他独奏，低、干，不要标题句
- 主歌设计：一行歌词唱满一小节，行尾留一拍空；每两行后再留 1–2 拍
- 副歌设计：Hook 用长音，四个字不要塞进两拍；「故乡」「那天」拉长
- 间奏或桥段：鼓与贝斯抽离，只留吉他和更慢的低声
- 结尾设计：编制收回，吉他空弦余响，不完满终止

## 人声设计

- 演唱语言：中文
- 声线：成年男声，低沉、厚重、有分量，很适合唱故事性民谣；干、近、不薄、不亮
- 唱法：慢咬、拉元音，不要说话赶词，不要说唱式吐字
- 情绪推进：全程保持慢；第二段只加一点力度，不加快
- 和声与叠唱：尽量少；若加，只用低八度

## 制作质感

- 混音空间：近人声、干房间
- 动态：自然，不过度压缩
- 音色：吉他有旧弦声，人声有胸腔
- 特殊效果：少量磁带感，不要闪亮高频

## 避免元素

- 赶词、说唱式吐字、把一行字塞进两拍、女声、薄亮男高音、少年音、气声甜歌、明亮民谣、苦情嘶吼、密集转音、宏大弦乐、EDM、厚重摇滚鼓、金黄怀旧、励志结尾、高音冲顶、港口、巷口、城市街道、歌词出现「农村」

## 参考方向

- 参考作品：不点名具体歌手；借鉴字少拍多的慢唱民谣
- 借鉴维度：留白、长音、后于拍点
- 明确不模仿的部分：旋律、歌词、标志性音色与具体演唱特征
