# Inspiration

Record song ideas that are not formally started yet. One idea can be a single line, or its own Markdown file.

Suggested fields:

- Working title
- One-line theme
- Core emotion
- Visual sentences
- Reference music or sound
- Intended vocalist and language

After the user explicitly agrees to start writing, run from `music-mv/`:

```bash
npm run create-song -- --title "歌名" --slug "english-slug"
```

Then move the relevant notes into the new song brief.
