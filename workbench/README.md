# 声场 · 单曲创作工作台

纯前端 Vue 3 页面，用于对照 `../music-mv/` 中的歌曲数据，并按段落写回歌词。本目录不保存歌曲档案或生成素材。

```bash
npm install
npm run dev
```

页面支持：

- 按 `lifecycle` 浏览创作中 / 已完成歌曲，以及灵感池、公共素材
- 查看从企划到成片的流程看板
- 一键复制完整歌词或提示词
- 按段落编辑歌词并写回 `song.json`
- 中英文提示词切换
- 点击歌词段落联动对应 MV 镜头
- 按时间码对照歌词和 MV 脚本

开发时 Vite 插件只读取相邻的 `music-mv/` 目录。源码规范见 `AGENTS.md`。
