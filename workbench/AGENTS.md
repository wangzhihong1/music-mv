# Vue 工作台规范

本目录是纯前端 Vue 3 工作台，用于展示、对照 `../music-mv/` 中的歌曲数据，并允许在歌词页写回已有段落的歌词。不要在本目录存放歌曲 Markdown、音频、角色资产、生成视频或 ComfyUI 工作流。

## 技术边界

- 使用 Vue 3、Vite、Composition API、单文件组件。
- 按模块拆分：`src/components/`、`src/composables/`、`src/api/`、`src/constants/`、`src/lib/`、`src/utils/`。
- 组件使用 PascalCase 多词命名；页面文案使用中文，源码文件名使用英文。
- 不要引入数据库、后端框架或与歌曲生成无关的依赖。
- 本地开发时，`plugins/studio-library-plugin.js` 从 `../music-mv/songs/` 读取 `song.json`、Markdown 和同一目录中的生成成品，通过 `/studio-media/` 提供预览，不得把数据或媒体复制进 `src/`。歌词保存接口只更新已有段落的 `lyrics`，不得增删段落或改写其他字段。佳句读写 `../music-mv/library/lyric-lines.json`，接口只增删改句子和备忘。人物 vlog 只从 `character.json` 读取并展示。工作台不填写 vlog；删除分镜的接口只去掉这一镜和对应视频文件，不得改写定妆、作品或其他字段。
- 建歌、校验 `song.json`、音频分析属于 `music-mv/`，不要写进本目录。

## 页面职责

- 展示创作中 / 已完成歌曲（按 `song.json` 的 `lifecycle` 过滤）、佳句和公共素材。公共素材页可选择并预览 `../music-mv/library/` 下的 Markdown 文档；佳句页可增删改查用户记下的句子，数据写入 `../music-mv/library/lyric-lines.json`。
- 展示从企划到成片的流程状态；MV 制作顺序固定为“MV 故事 → 脚本骨架 → 人物/场景基准图 → 最终分镜提示词 → 分镜视频 → 修复超分 → 成片”。点击“脚本骨架”只展示镜头时间线与导演执行信息，不展示提示词；“人物/场景基准图”展示由人物档案 `works[].songId` 关联的 `look.threeView` 和歌曲 `assets/scenes/` 中的场景基准图，不展示人物提示词；“最终分镜提示词”展示每镜可复制的中英文提示词；分镜视频、修复超分和成片以磁盘上的实际文件为准。
- 在「本机成片」中预览从人物档案引用的三视图、场景基准图、分镜视频、超分中间件、成片和原曲。
- 在歌曲页的「Shorts」里，从当前歌曲挑选一段不超过 60 秒的精彩片段，写成 YouTube Shorts 的竖屏短视频条目。这不是整支 MV，不进入 MV 制作流程。条目保存在该歌 `song.json` 的 `shorts`。短视频保存接口只替换 `shorts`，不得改写歌词或其他字段。时间范围内已经生成的当前分镜视频，以及这条短视频登记的成片，直接在对应条目里播放。
- 人物详情默认只留封面、名字、职业、三视图和 vlog。简介、性格、定妆词、声音、作品、关系和禁忌收在「人物资料」弹层里。日常视频是合成视频列表，点开一条才进入这支 vlog：拍摄主题、对镜头独白、状态、分镜视频、合成视频和发布文案。独白写在条目的 `monologue`，这一镜要说的话写在分镜的 `line`。分镜视频可以删除，删除会去掉这一镜和对应文件；若已完成的总长因此不够 15 秒，状态回到制作中。一条 vlog 是 15 到 30 秒的竖屏日常，不进入 MV 制作流程。一件事用多个机位来拍，每个分镜 1 到 12 秒。视频放在人物目录的 `vlog/` 下。工作台不在这里填写 vlog，也不提交 ComfyUI。
- 对照歌词、风格提示词和 MV 分镜，支持复制。人物定妆提示词只在「人物」详情展示；歌曲的「人物/场景基准图」只预览已关联的人物三视图与场景参考图。
- 歌词页可按段落修改 `sections[].lyrics`，经本地开发接口写回对应 `song.json`。不增删段落，不改写其他档案字段。企划、提示词、分镜和其余档案仍由 Agent 按 `music-mv/AGENTS.md` 更新。
- `song.json` 或 `character.json` 变更时静默重新拉取工作台数据，不要整页刷新；歌词编辑过程中暂停这次刷新，保存或取消后再恢复。

## 开发约定

- 新增界面先抽组件，再接到现有 composable，避免把逻辑堆回 `App.vue`。
- 样式沿用现有色板与间距，不另起一套视觉系统。
- 修改 UI 后，在浏览器中走一遍：切歌、切分类、总览、MV 对齐、本机成片、点击流程步骤、复制、编辑歌词、保存、取消。改到佳句时，再走一遍记下、查找、修改、删除。改到人物页时，打开并关闭人物资料；改到人物 vlog 时，从合成视频列表点进详情，确认能看到主题、状态、分镜视频、合成视频和发布文案，并走一遍删除分镜后返回列表。
- 在本目录运行 `npm run lint` 与 `npm run build`；不要把 `music-mv/` 的校验绑进前端构建。
