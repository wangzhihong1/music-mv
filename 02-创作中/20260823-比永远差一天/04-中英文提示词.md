# 《比永远差一天》Mureka 专属风格提示词

仅用于 Mureka 的“风格”输入框，共 564 字符（含标点）。

```text
Mandarin Piano Ballad，64 BPM，6/8拍，温柔、成熟、遗憾；整体比常规慢歌更舒展，每小节只感受两个缓慢大拍，主唱略后于拍点，钢琴与鼓不要填满细分。每两行后留1–2拍空白，副歌用长音推进而非增加字密度。8小节Felt piano纯器乐前奏；第一遍副歌后留8小节钢琴与大提琴间奏；结尾短尾奏。年轻清透女声，近距离收音，咬字清楚，可听见呼吸；使用气声、胸声到头声的顺滑衔接、集中混声、克制滑音、少量转音与窄幅颤音。“，”为半拍停顿或换气，不要赶拍。第一段主歌低音区轻唱；预副歌缓慢上行。第一遍副歌进入中强度混声，“永远”轻抬，“那一年”的“年”延长三拍。第二段真声略增；第二遍副歌保持慢速主旋律，鼓、贝斯与薄和声加入，但维持半拍律动，“告别”短下滑。桥段撤掉鼓与贝斯。最终副歌前四句近乎清唱，从“你没有说谎”全编制进入：有力度的钢琴、完整但稀疏的鼓组、低音、宽阔弦乐与八度和声；不要加速。“换不回那一天”持续推高，随后升全音进入释放段。“如果爱过”强起，“时间”一次上行转音；“会照亮，没有你的明天”为最高点，“天”以集中混声延长四拍并加入受控颤音。最后“只比永远差一天”完整连唱，只延长末字“天”，随后骤然收回钢琴。高潮强烈、宽阔、催泪但不嘶吼；避免密集转音、连续颤音、快鼓花、摇滚吼唱、EDM和过度励志。
```

## 使用说明

- 歌词框只粘贴 [03-歌词.md](./03-歌词.md) 的“歌词正文”，保留段落标签。
- 使用相同歌词与提示词生成 3–4 个版本，第一轮只比较副歌 Hook、中文咬字和长句换气。
- 第二段主歌与第二遍副歌只做小变化，不改变整首歌的主旋律身份。
- 提示词不写具体歌手或作品名，让 Mureka 聚焦情绪、唱法和声音演进。
- 歌词框中的标点负责分句和延音；气声、真假声、滑音、转音与颤音由本提示词指定。
