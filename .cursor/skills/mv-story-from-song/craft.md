# 编剧手艺

本文件只给方法。仓库流程、字段和停写规则以 `SKILL.md` 与 `music-mv/AGENTS.md` 为准。

方法来源压缩成可执行规则，不复制外部技能正文：叙事锚点与「用身体写情绪」参考 [smixs/visual-skills](https://github.com/smixs/visual-skills)（Serge Shima，CC BY 4.0）；「先总谱后单场」参考 [huangserva/musical-mv-storyboard](https://github.com/huangserva/musical-mv-storyboard) 的导演总谱思路；歌词对位参考 [guigulaoshi/music-video-director-skill](https://github.com/guigulaoshi/music-video-director-skill) 的四种意象关系。默认时长、关键帧、Seedance/Kling 语法和整份 prompt **一律不采用**。

## 编剧立场

只需要拿歌的主题去发展故事，场景中不一定有人，也不一定只有一个主角，都是多元化的。

你不是在给歌词做分镜预告片，也不是在写一个人的人物传记。先问：把歌词拿掉，这个世界还是不是这首歌的主题？如果还可以套到任何同类歌曲上，重写。

## 歌曲解码清单

写故事前用当前档案填完，缺一处就回去读文件，不要靠印象：

- 核心创作句
- 叙事者是谁；画面是否需要贯穿主角（默认不需要）
- Hook 原句（必须在故事里被看见或被回应，不是当标题飘着）
- 两到四个可变的核心意象
- 情绪从哪来、在哪折、在哪放、在哪收
- 用户已禁止的内容

## 一场戏的最低配置

开写任何一段之前，用一句话点名：

- 主题：这一场把歌曲主题往哪推
- 世界：地方、天气、日子还是人群
- 在场：可以没人，可以是不同的人，不要默认同一张脸
- 目光：观众第一眼必须看见什么

空景只要推进主题，就是戏。没有人，不等于没有故事。

## 母题怎么选

好母题同时满足：

1. 从歌词或歌曲主题长出来，不是外挂奇观
2. 能在开场出现，并在转折或高潮改变形态
3. 能被道具、光线或构图反复指认
4. 在这首歌所属的生活里可信（都市、乡村、室内或空景都可以）；不要把所有歌都拍成咖啡馆和天台

弱母题：雨、路灯、天台、咖啡馆对望——只有当这首词把它们写成不可替代的事件时才能用。

## 五种常见翻车

| 翻车 | 改法 |
| --- | --- |
| 逐句配画面 | 只拿主题长场景，少数节点才对词 |
| 全片一个主角跟拍 | 空景、众人、一闪而过的人都可以承担主题 |
| 通用都市情伤 | 回到解码清单，用这首歌独有的主题重建世界 |
| 加车祸、出轨、死亡、新恋情 | 删除。歌曲没授权的情节不是戏剧性 |
| 用「孤独/释然/心碎」写人 | 改成手、目光、呼吸、停住的物件 |
| 结尾强行振作或撕毁过去 | 落到核心创作句允许的温度；《比永远差一天》带走旧照片而不是毁掉它 |

## 样本：两种对照，都不当作下一首的模板

《故乡》说明主题怎么长成多元世界：主体是村里的日子，开场可以没人，发展可以是不同的人，乳名只是一声，高潮可以再回到空田。不要把下一首歌也写成故乡。

《比永远差一天》说明主题很具体时，也可以收成一件事。只借「贴这首歌」的结构，不要把照相馆故事套到下一首歌。

- **情绪**：承诺当时是真的，只是没抵达永远
- **母题**：年度合照 / 显影
- **道具**：照片背面的「明年见」
- **破裂**：看懂距离与真心同时存在
- **最终画面**：她独自入镜，旧照片仍被带走

歌词里的相纸、明年见、差一天，被翻译成一次取件、一次显影、一次独自入镜。主歌用同一构图看关系变疏，副歌用快门对齐释放。没有背叛，没有死亡，没有新欢。这就是「贴这首歌」，不是「贴情歌类型」。

## 提交口吻

把用户当制片人。先讲一句话故事和五个锚点，再讲五段。解释为什么这个事件只能属于这首歌。修改时改事件和母题，不要用更华丽的句子掩盖结构问题。
