# 编导手艺

本文件只给方法。门槛、字段和校验以 `SKILL.md` 与 `music-mv/AGENTS.md` 为准。H3 六段格式以 `music-mv/library/h3-prompt-writing.md` 为准。

方法来源压缩成可执行规则，不复制外部技能正文：「先总谱再单镜、镜头交接与反差」参考 [huangserva/musical-mv-storyboard](https://github.com/huangserva/musical-mv-storyboard)；「全片覆盖职责、相邻段必须换覆盖方式、口型克制、歌手不必每镜出现」参考 [tjsdyy/MusVideoPrompt](https://github.com/tjsdyy/MusVideoPrompt)；「镜头要有身体事实和移动理由」参考 [smixs/visual-skills](https://github.com/smixs/visual-skills)（Serge Shima，CC BY 4.0）。10–15 秒生成段、逐镜关键帧、Seedance 参数和 EDL 渲染链 **一律不采用**。

## 编导立场

你不是在给模型堆形容词，而是在排一场必须踩着这首歌走的戏。

先问：这一镜删掉以后，故事还通不通？不通就留下；通了，再看它是否只是「好看」。好看但无职责的镜头删掉。

## 总谱最小集

拆镜前用当前已确认故事填完：

- 导演论点：一句话说明全片让观众看见什么变化
- 歌曲结构与能量：哪一段建立、哪一段加压、哪一段释放
- 视觉章节：每个章节的世界状态、视觉语言、对应故事阶段
- 爆点窗口：最终副歌或用户指定的最强句，必须有专镜
- 母题如何入画：开场以何种形态出现，高潮变成什么

没有总谱就写 prompt，项目会退化成单镜炫技。

## 职责怎么轮

给每一镜一个主职，相邻镜不要重复主职：

| 职责 | 做什么 |
| --- | --- |
| 叙事动作 | 人物做成一件改变处境的事 |
| 关系/反应 | 看见缺席、距离或另一人留下的痕迹 |
| 细节插入 | 道具、手、母题的近处变化 |
| 环境切出 | 空间压力，不演脸 |
| 象征切出 | 母题的隐喻形态，仍要可拍摄 |
| 表演近景 | 中近景连接观众；口型只放在这里 |

演唱近景放在歌词或情绪最需要直视观众的位置，并与叙事镜在服装、光线或动作上呼应。

## 镜间交接

写 `action` 时带上交接，不要只描写画面内部：

- 接住：上一镜结束时观众停在哪
- 推进：本镜让欲望、阻碍或理解发生什么
- 推向：下一镜必须因此变得不可避免或突然反差

反差至少换一个维度：远/近、静/动、冷/暖、空间/身体、单人/痕迹中的另一人、慢推/锁定。

「女主站着、金光、正面」连拍三镜，即使单张能过 H3，全片也没有导演。

## 一镜一个事实

`action` 必须是摄影机能录到的事：

- 环境压力：湿玻璃、钨丝灯、暗房红光
- 身体微动作：扶椅、落笔、胸腔打开一寸、肩落下
- 母题或声音锚点：门铃、快门、相纸入水

禁止用「孤独地」「悲伤地」「史诗感」代替上述事实。镜头移动必须回答「什么变了」；没变就固定。

## 歌曲对位

- 关键句要有画面或情绪回应，但不需要每句切一镜
- 切点落在乐句结束、呼吸、鼓点或结构切换，不要切在一个字的元音中间
- 平均镜头长度跟随能量：主歌可较长，预副歌收紧，副歌爆点前后留出停顿再冲击
- 用户指定只拍某段时，五段叙事功能仍要在该时长内落实，只是事件收窄

## 提示词位置

先锁分镜表里的动作、景别、交接和声画重点，再翻译成 H3 六段。提示词不得改写已确认故事，不得在 `detailed_description` 里另发明情节点。模型语法、脸占比、眼神持住、闭唇生成，全部交给 `h3-prompt-writing.md`。
